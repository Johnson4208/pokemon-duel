# Pixel VFX used in Pokémon Duel

The game combines selected animations from user-supplied asset packs into a runtime atlas. Original archives, editable sources, coupons, and standalone asset downloads are not published.

- Frostwindz: Priest, Frost Knight, Necromancer, Starcaller, Warlock, Blood Mage, and Warrior free packs. Included license permits incorporation and modification in games. Attribution is appreciated; source packs are not offered for reuse.
- CodeManu and Davit Masia: Free Pixel Effects Pack. Included README declares the assets public domain.
- User-supplied Pixel VFX Essentials, DarkSpells, Acid VFX 01–02, Ice Effect 01, Wood VFX 01–02, Smoke Effect 01, and Smear VFX 01.

These assets are used as game graphics; no AI model training is performed.
