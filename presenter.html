Tài liệu đã lưu

File tự lưu trên trình duyệt của thiết bị này, không tải lên mạng và chưa đồng bộ sang máy khác.

Xóa dữ liệu trình duyệt có thể làm mất file đã lưu. Dùng “Tải file gốc” để giữ bản sao; bản tải xuống không kèm nét vẽ.

Kéo thả file vào đây hoặc chọn “Mở PDF / PowerPoint”.
